ADD YOUR LOGO HERE
==================

Save the Guardian Medical Services logo (the shield + "GUARDIAN MEDICAL SERVICES"
wordmark you provided) in THIS folder as:

    logo.png

Recommendations:
- Transparent background PNG
- ~500–800px wide (it's displayed at 56px tall in the nav, ~230px in the hero)
- Keep the file under ~200 KB if possible for fast loading

The site already references images/logo.png in the header, hero, and footer of every
page. Until you add the file, the site automatically falls back to a styled text
wordmark + an SVG shield, so nothing looks broken.

A favicon (browser-tab icon) is already provided as favicon.svg — no action needed.
